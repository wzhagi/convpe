\begin{abstract}
	ConvPE substantially improves Transformers parameter efficiency and training efficiency by Convolutional Position Embedding. ConvPE achieves substantial reductions in validation loss compared with the Rotary Position Embedding (RoPE) baseline, while adding only a small number of backbone parameters (+0.15\% params, -3.83\% loss; +1.87\% params, -8.03\% loss). As model scale increases, the best configuration achieves a 10.3\% loss reduction with only a 4.34\% increase in backbone parameters, demonstrating high performance and parameter efficiency. ConvPE uses convolution to generate attention score biases, making it compatible with various Transformer architectures and high-dimensional modalities. The code for ConvPE is publicly available at \url{https://github.com/wzhagi/convpe}.
\end{abstract}
\keywords{Position Embedding \and Language Models \and Transformers \and Attention}

Transformers~\cite{vaswani2017attention} are insensitive to input order. However, word order is crucial for language understanding. Explicit or implicit position embeddings are therefore necessary to inject order information into the model~\cite{devlin2019bert,radford2019language,su2021roformer}.

This paper proposes ConvPE, a novel and efficient position embedding scheme. ConvPE embeds position information into attention score biases, trading a minor parameter overhead for significant performance gains, as shown in Figure \ref{fig:fig1}. Its design allows the model to switch freely between different attention masks and is compatible with various Transformer architectures. It also naturally supports high-dimensional modalities with n-dimensional convolution.

The main contributions of this paper are as follows:

1. We propose the ConvPE architecture that combines high performance and broad compatibility.

2. We systematically study the influence of ConvPE architecture and hyperparameters through language model training.

3. We verify the effectiveness of ConvPE in scaling experiments.

4. We verify the effectiveness of ConvPE2D in visual model training.


\section{Background}

\subsection{Attention Mechanism}


Given the input query $
Q \in \mathbb{R}^{T \times d_k}$ , key $K \in \mathbb{R}^{S \times d_k}$, and value $V \in \mathbb{R}^{S \times d_v}$, the computation of scaled dot-product attention~\cite{vaswani2017attention} $O\in \mathbb{R}^{T \times d_v}$ is:

$$
O = \mathrm{Attention}(Q,K,V) = \mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}} + \mathbf{B}\right)V
$$

$T$ is the query sequence length. $S$ is the key/value sequence length. $\mathbf{B}\in\mathbb{R}^{T\times S}$ is the attention score bias. Causal models introduce a causal mask $M\in\mathbb{R}^{T\times S}$ that sets the attention score bias $\mathbf{B}$ for invisible positions to $-\infty$. With batch size and multi-head settings, $Q,K,V,O$ additionally have $B,H$ dimensions.

\subsection{Position Embedding}
Existing position embedding schemes can be roughly divided into five categories:

1. \textbf{Absolute Position Embedding}\cite{vaswani2017attention}: adds a fixed positional bias, usually sine waves, to the input vector. It is simple to implement, but its performance is usually limited.

2. \textbf{Learnable Positional Bias}\cite{devlin2019bert,radford2019language}: adds a learnable positional bias to the input sequence. It is typically adopted in limited-window settings, such as spatial dimensions in vision models or fixed-rate compression.

3. \textbf{Rotary Position Embedding}\cite{su2021roformer}: encodes position as a rotation matrix and applies it to queries and keys, so that attention scores depend on relative positions. RoPE has been widely adopted in modern large language models, enabling long-context extension via frequency scaling, such as YaRN\cite{peng2024yarn}.

4. \textbf{Attention Score Bias}: adds a positional bias $B$ to attention scores, such as T5 relative position bias\cite{raffel2020exploring} and ALiBi\cite{press2021train}. RoPE can be viewed as a rotation-based equivalent, as it also makes attention scores depend on relative positions.

5. \textbf{No Position Embedding (NoPE)}\cite{kazemnejad2023impact}: adds no explicit position embeddings; instead, it relies on model structure and causal attention masks to implicitly learn positional information, as in Kimi K3\cite{kimi2026k3}, requiring no explicit position extension.


\section{Method}

ConvPE is a convolutional attention score bias method. Its goal is to construct an attention score bias tensor $\mathbf{B_{ConvPE}}\in\mathbb{R}^{B\times H\times T\times W}$ for self-attention tokens within the convolution window. Tokens outside the window use no attention score bias.

\begin{figure}[!ht]
    \centering
    \begin{minipage}{0.20\textwidth}
    \includegraphics[width=\linewidth]{FIGURES/attn_score_bias.png}
    \end{minipage}
\end{figure}

\begin{equation*}
\mathbf{B}^{b,h,t,s}=
\begin{cases}
\mathbf{B}_{\mathrm{ConvPE}}^{b,h,t,w}, & w\in [0,W-1] , w=s-t+W-1\\
0, & \text{otherwise}.
\end{cases}
\end{equation*}




The hyperparameters include:
\begin{itemize}
\item $W$: convolution window size.
\item $C_{s}$: number of convolution input channels for shared projection.
\item $G_{s}$: number of convolution groups for shared projection.
\item $C_{h}$: number of convolution input channels for headwise projection.
\item $G_{h}$: number of convolution groups for headwise projection.
\end{itemize}
There are two ways to obtain $\mathbf{B}$ from the layer input $X\in\mathbb{R}^{B\times T\times D}$. ConvPE adopts the form of adding the two biases:

$$
\mathbf{B}_{ConvPE}=\mathbf{B}_{s}+\mathbf{B}_{h}
$$

\subsection{Shared Projection}

The shared projection layer $W_s$ is used to downsample $X$. To adapt to the convolution layer input format $(B,C,T)$, the last two dimensions need to be swapped:

$$
I_{s}=(W_{s}X)^\top
$$

After left-padding $W-1$ zeros, pass it through a convolution layer:

$$
O_{s}=
\mathrm{Conv1d}(C_{s}, H \times W, W, G_{s})(\mathrm{Pad}(I_{s}))
$$

$\mathbf{B}_{s}\in\mathbb{R}^{B\times H\times T\times W}$ is obtained by applying dimension transformation to $O_{s}$. 

Note that unflatten $O_{s}\in \mathbb{R}^{B \times C \times T }$ into $O_{s}\in \mathbb{R}^{B \times (W \times H) \times T }$ or $O_{s}\in \mathbb{R}^{B \times (H \times W) \times T }$ is asymmetric when $G_{s} \ne 1$. 

The projection parameter count is $D \times C_{s}$, and the convolution parameter count is $W^2 \times H \times C_{s} / G_{s}$.

\subsection{Headwise Projection}

The Headwise projection layer $W_h$ is used to downsample $X$:

$$
I_{h}=W_{h}X
$$

Then convert $I_h\in \mathbb{R}^{B\times T\times (H \times C_h)}$ into $I_{h}\in \mathbb{R}^{(B \times H)\times C_{h} \times T }$ using dimension transformations.
After left-padding $W-1$ zeros, pass it through a convolution layer:

$$
O_{h}=\mathrm{Conv1d}(C_{h}, W, W, G_{h})(\mathrm{Pad}(I_{h}))
$$

$\mathbf{B}_{h}\in\mathbb{R}^{B\times H\times T\times W}$ is obtained by applying dimension transformation to $O_{h}\in \mathbb{R}^{(B \times H) \times W \times T }$. 

The projection parameter count is $D \times H \times C_{h}$, and the convolution parameter count is $W^2 \times C_{h} / G_{h}$.

\section{Experiments}
All models used in these experiments are Multi-Query Attention (MQA)\cite{shazeer2019fast}, with $K=V$\cite{deepseek2026v4}. The attention layers parameter count is $dim\_model \times dim\_heads \times (2 \times num\_heads+1)$. The feed-forward layers use SwiGLU\cite{shazeer2020glu} with a total parameter count of $dim\_model^2\times 8$. The models are trained for one epoch on WikiText-103\cite{merity2016pointer}, after which validation loss is recorded. We used the Hugging Face Trainer\cite{wolf2020transformers} for training, AdamW\cite{loshchilov2019decoupled} as the optimizer, and GPT2Tokenizer\cite{radford2019language} as the tokenizer. The training hyperparameters are: batch\_size=4, learn\_rate=3e-4, block\_size=1024, lr\_scheduler\_type="cosine", weight\_decay=0.01, max\_grad\_norm=1.0, seed=42.

\subsection{Architecture and Hyperparameter Evaluation}
\label{sec:ahe}

The model parameters used in this round are $N_{layers}=6$, $D_{model}=192$, $N_{heads}=3$, $D_{head}=64$. The main model has 2.3M parameters, and the embedding layer has 9.6M parameters.

ConvPE has 5 hyperparameters, for example: $W=64,C_{s}=16,G_{s}=8,C_{h}=4,G_{h}=1$. We abbreviate this configuration as the label $w64s16g8h4g1$. If RoPE is used, we prefix the label with $r$, for example $rw64s16g8h4g1$. Since most experiments use $w128$, this configuration is omitted from the labels. If shared or headwise parameters are absent from the label, the corresponding mode is not used.

\subsubsection{Single-Mode Hyperparameter Evaluation}

Figure \ref{fig:2} shows the training results under single-mode configurations. Under all configurations, performance is substantially improved over the RoPE baseline. Intuitively, as $G$ increases, parameter efficiency increases and performance decreases; as $C$ increases, performance first improves rapidly and then enters a noisy slow improvement phase. We observed that $C_{h}\in [1,2,4]$ has the highest performance and parameter efficiency. Although shared mode is less parameter-efficient, it has greater potential for parameter scaling. $C_{s}=G_{s}$ has the fewest parameters and therefore the highest parameter efficiency.

\subsubsection{Window-Size Evaluation}

The parameter counts of both modes contain a $W^2$ term, indicating that reducing the window size can quickly lower the parameter count. Since $s16g16h4g1$ performed best in the previous round but has a relatively large parameter count, we evaluated $w64$, $w32$, and $w16$ for this configuration. Figure \ref{fig:4} shows that this series achieves the best performance at each parameter scale. We then tried $w2h1g1$, which has the theoretically smallest parameter count. The results show that reducing window size does not make ConvPE perform worse than the RoPE baseline; with only a 0.15\% increase in parameter count, the loss decreases by 3.659\%, reaching a ratio of 23.71.

As the window size increases, performance continuously improves while high parameter efficiency is maintained. This appears to be a promising scaling dimension.

\subsubsection{NoPE vs RoPE}

Since the $w2h1g1$ window is very small, we tried combining it with RoPE to achieve higher performance. Table \ref{table:1} shows that $rw2h1g1$ achieves the highest efficiency without increasing the parameter count, the loss decreases by 3.83\% relative to the RoPE baseline, reaching a new highest efficiency ratio of 25.3. We also tested other configurations in RoPE mode, and all performed worse than NoPE mode.

\subsubsection{Channel-Splitting and RoPE Integration}

Table \ref{tab:2} shows that as the backbone model scales, ConvPE performance improves. ConvPE + RoPE still performs worse than ConvPE alone. As the parameter proportion shrinks, parameter efficiency improves substantially, from 0.31 in the previous section to 2.37 (7.65$\times$).

Note that unflattening $O_{s}\in \mathbb{R}^{B \times C \times T }$ into $O_{s}\in \mathbb{R}^{B \times (W \times H) \times T }$ or $O_{s}\in \mathbb{R}^{B \times (H \times W) \times T }$ is asymmetric when $G_{s} \ne 1$. Experiments show that $C=W\times H$ is slightly better, but all earlier experiments used $C=H\times W$. We did not rerun the early experiments because the improvement is so small. However, the following experiments start to use $C=W\times H$ instead.

\subsubsection{No-Projection Configurations}

$hx$ means removing $W_{h}$ and using $X$ as the projection layer output.

Theoretically, any linear mapping $W \times D \rightarrow H \times W$ is equivalent to $sxg1$ while other configurations are its low-rank representations. The parameter count then becomes $W^2 \times H \times D$, which is too large and can only be tried with small windows or extremely large models.

Table \ref{tab:4} shows that both no-projection configurations perform worse. However, removing the shared projection layer can improve parameter efficiency.

\subsubsection{Multi-Epochs Training}

We trained ConvPE models and a RoPE baseline from scratch on WikiText-103 for 10 epochs. Figure \ref{fig:fig5} demonstrates the remarkable superiority of the ConvPE architecture. The training and validation losses of ConvPE consistently remain substantially below those of the baseline, showing exceptional training efficiency and generalization capabilities. Notably, training ConvPE for merely one epoch surpasses the baseline trained for three epochs, and by epoch two, it already achieves a lower validation loss than the baseline's absolute best. Quantitatively, the best ConvPE validation loss reaches 3.1623 (ppl 23.62), which is 6.66\% lower than the baseline's best of 3.3879 (ppl 29.60).

While ConvPE fundamentally outperforms the baseline, the performance gap between its RoPE and NoPE variants is marginal, though their generalization dynamics differ slightly. In low-epoch scenarios, the NoPE variant achieves a lower validation loss, indicating better early-stage generalization compared to its RoPE counterpart. Conversely, under multi-epoch training conditions, the RoPE variant catches up and yields a slightly lower generalization loss (e.g., 3.1623 vs. 3.1676 at epoch 6), and shows less overfitting with similar training loss. Additionally, regarding training set optimization, the NoPE variant maintains a consistently lower training loss than the RoPE variant throughout the entire training process.

\subsection{2D Vision Position Embedding}

To produce 2D positional embeddings, we use 2D convolutional layers. Instead of using a local windowed attention bias $\mathbf{B_{ConvPE}}\in\mathbb{R}^{B\times H\times T\times W}$, we use a global attention bias $\mathbf{B_{ConvPE2D}}\in\mathbb{R}^{B\times H\times T\times T}$, where $T$ is the sequence length after embedding the image. Note that the input window size $W$ and the output window size $W_{out}$ in output channel dimension of the convolution layer can be different.

We trained Multi-Head Attention (MHA) ViT-Tiny\cite{dosovitskiy2021image} models with configuration $N_{layers}=12$, $D_{model}=192$, $N_{heads}=3$, $D_{head}=64$. ConvPE2D configuration is still $s16g16h4g1$ but with $W_{out}=T$. We used the Muon\cite{jordan2024muon} optimizer to optimize the 2D parameters, excluding the embedding layer, with a learning rate of 3e-3, while the remaining parameters were optimized with AdamW at a learning rate of 3e-4. We trained the models on CIFAR-10 and CIFAR-100\cite{krizhevsky2009learning} for 100 epochs with batch\_size=256, patch\_shape=(4,4).

Table \ref{tab:5} shows that ConvPE transfers effectively to Vision Transformers and outperforms the RoPE baseline. Increasing the window size improves validation accuracy on the harder dataset CIFAR-100, while CIFAR-10 remains nearly saturated and favors the smaller w3 window.

\section{Conclusions and Future Work}

ConvPE delivers substantial performance gains at a minor parameter cost, providing a powerful and parameter-efficient alternative for Transformer position modeling.

Based on our experiments, we summarize the following practical tuning guidelines:
\begin{itemize}
	\item \textbf{Adopt $s16g16h4g1$ as the default configuration.} It achieves an optimal balance between performance and parameter efficiency.
	\item \textbf{Scale the window size.} Increasing the window size yields continuous performance improvements.
	\item \textbf{Expect larger gains at larger scales.} As the backbone model grows, ConvPE tends to deliver greater performance improvements and higher parameter efficiency.
\end{itemize}

ConvPE is compatible with different attention masks and KV-cache concatenation, and it naturally supports multidimensional extension. Future work can explore the following directions:
\begin{itemize}
    \item \textbf{Optimized kernels}. ConvPE incurs a computational cost increase that is only slightly higher than its parameter increase; with high-performance kernels, its training time can be further reduced.
	\item \textbf{Scaling behavior.} Investigate ConvPE with larger Transformers and datasets, and identify configuration patterns at scale.
	\item \textbf{Long-context modeling.} Evaluate ConvPE in long-context settings, where positional generalization is particularly important.
	\item \textbf{Architectural integration.} Combine ConvPE with Sliding Window Attention (SWA)\cite{beltagy2020longformer}, Compressed Sparse Attention (CSA)\cite{deepseek2026v4}, and other Transformer variants.
	\item \textbf{Multidimensional modalities.} Extend ConvPE to high-dimensional modalities such as video, speech, and multimodal learning.
\end{itemize}
